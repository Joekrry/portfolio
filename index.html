Assessing the Galea Headset on a Benchmark of Deep Learning Architectures and Pre-processing Pipelines for EEG Motor-Imagery Task Classification
I built EEGCHTB, a leakage-safe benchmarking framework, to test how well EEG motor-imagery decoders hold up when moved from dense research montages onto the sparse four-channel montage of the OpenBCI Galea headset. It crosses three models (EEGNet, EEG-Conformer, and my own GRF-Net) with four preprocessing pipelines across the BCI Competition IV-2a and IV-2b datasets, backed by a resumable grid runner and 215 tests. I found that the montage mattered more than the architecture: dropping to the Galea montage cost roughly 5 to 15 accuracy points, a Friedman test separated the three models in only 4 of 12 cells, and every model still beat chance. The result points to signal quality and channel coverage, rather than model choice, as the dominant factor.

GRF-Net: Geometry-aware Rocket-Fusion Network Open source
A novel compact deep learning architecture for multichannel time series, originally tailored to EEG data.
I designed and open-sourced (MIT) GRF-Net, a compact PyTorch model for multichannel time-series classification. It combines learned spatial filters over the input channels (optionally seeded from 10-20 electrode geometry), a mostly frozen ROCKET-style bank of dilated convolutions, and fusion pooling (PPV, log-variance, mean) through a learned gate into a small linear head. The frozen bank keeps the model to around 3,400 trainable parameters. On cross-subject left versus right motor imagery across all 109 EEGMMIDB subjects, it reaches 0.805 balanced accuracy against a chance level of 0.50.

Convolutional Vision Transformer – Temporal Convolutional Network (CvT-TCN) for EEG Motor Imagery Classification Open source
Independent CvT-TCN experiment for EEG motor imagery classification.
I built a Convolutional Vision Transformer in PyTorch to deepen my understanding of attention-based models on 4-class EEG motor imagery, using the EEGMMIDB dataset. It matched EEGNet's subject-independent accuracy end-to-end, and I visualised the attention maps and filter activations to confirm they aligned with known motor-imagery neurophysiology.

ParticlePipe Open source
High-energy-physics data pipeline and analysis platform (LHC Run 3 simulation).
I built ParticlePipe in pure Python (no ROOT or NumPy) to work through the physics and engineering of a collider data pipeline from first principles. A seeded Monte Carlo generator simulates LHC particle collisions and a three-level asynchronous trigger reconstructs them, recovering the Z boson and J/ψ mass peaks at their expected energies through a CLI and a streaming FastAPI service.

CaMLL Open source
Classical Machine Learning / Deep Learning library written in raw C11.
I started CaMLL to build a strong, code-level understanding of machine learning by implementing it from scratch in raw C11 with zero dependencies. It provides hand-written row-major matrix and vector types over a custom arena allocator, a seeded xorshift PRNG, CSV loading with train/test splits and standardisation, and linear regression via both the closed-form normal equation and gradient descent, with the longer-term aim of serving as a native, low-latency analysis layer for ParticlePipe.

vimline-errors Open source
An open source inline error diagnostic tool for native Vim 9.0+.
